# 달빛뷰어 (Dalbit Viewer)

**Windows용 무료 이미지 뷰어. 광고 없음, 설치 없음, 약 14MB.**

JPG·PNG·GIF·WebP·AVIF·TIFF·BMP 이미지를 열 수 있고, 만화책 압축파일인 **CBZ·ZIP을 풀지 않고 바로** 볼 수 있는 초경량 이미지 뷰어입니다. GIF/WebP 애니메이션 재생, 전체화면 감상, 폴더와 압축파일 자동 넘김을 지원합니다.

이미지를 보는 시간, 방해받지 않도록.

광고도, 설치도 필요 없습니다. UI는 시야를 가리지 않으며, 이미지를 여는 순간부터 보는 일에만 집중하세요.

## 주요 특징

### 원하는 대로 폴더와 압축파일을 순서대로 넘겨 봅니다

만화나 사진을 폴더별로 정리해 두고, 하나를 다 보면 자동으로 다음 항목으로 넘어갑니다.

- 폴더는 폴더끼리, 압축파일(CBZ/ZIP)은 압축파일끼리 이어집니다. 섞이지 않습니다
- 이름 오름차순·내림차순, 수정날짜 오름차순·내림차순으로 순서를 정합니다
- 이미지가 없는 폴더는 건너뜁니다
- 이동 범위는 처음 연 항목의 상위 폴더 안으로 고정됩니다. 상위 폴더로 새어 나가지 않습니다
- 끝에서 멈추거나, 처음으로 돌아가거나, 다음 항목으로 넘어가는 동작을 고를 수 있습니다

### 다 본 항목을 한 번에 정리합니다

`L` 키로 열람한 목록을 열면, 그동안 본 폴더와 압축파일이 자동으로 쌓여 있습니다.

- 체크박스로 여러 항목을 고르고 **전체 선택**으로 한 번에 지정합니다
- **휴지통으로 이동**으로 실제 폴더·압축파일을 Windows 휴지통에 보냅니다
- **목록에서만 제거**로 디스크는 그대로 두고 목록만 정리합니다
- 드라이브 루트, 사용자 홈, Windows 기본 폴더, 시스템 폴더는 실수로도 삭제되지 않게 막혀 있습니다

### 화면을 이미지로 채웁니다

- 전체화면으로 열리고, 상단 바는 마우스를 화면 위로 올릴 때만 나타납니다
- 커서는 2초 뒤 사라지고, 움직이면 다시 나타납니다
- 하단 슬라이드바로 현재 폴더 안을 빠르게 건너뜁니다
- 배경색을 검정·어두운 회색·흰색 중에 고릅니다

### 압축파일을 풀지 않고 봅니다

- ZIP, CBZ를 그대로 열어 안의 이미지를 넘겨 봅니다
- 만화 보관용으로 폴더를 정리할 필요가 없습니다

### 보는 방식과 조작을 내 손에 맞춥니다

- 보간기법 6종: 픽셀아트는 NEAREST, 사진은 LANCZOS
- 마우스 휠을 이동용/확대용으로 바꾸는 두 가지 조합
- 주요 단축키를 직접 지정
- 한국어 / English

### 가볍고 흔적을 남기지 않습니다

- 광고, 계정, 추적, 인터넷 연결이 없습니다
- 설치 과정 없이 압축을 풀고 실행합니다
- 설정 파일은 프로그램 폴더 안에만 저장됩니다. 연결 프로그램으로 등록한 경우에만 Windows 레지스트리에 항목이 추가됩니다

## 실행법

**EXE로 실행**

[Releases](https://github.com/sogid92/dalbit-viewer/releases)에서 `DalbitViewer-<버전>-win64.zip`을 받아 압축을 풀고 `DalbitViewer\DalbitViewer.exe`를 실행합니다.

**소스로 실행** (Python 3.10 이상)

```bat
pip install -r requirements.txt
python main.py [이미지 / 폴더 / ZIP / CBZ 경로]
```

경로를 생략하면 파일 선택 창이 열립니다. 이미지 파일 대신 폴더나 압축파일을 열 수도 있습니다.

## 연결 프로그램 설정

압축파일 우클릭 메뉴에 **달빛뷰어로 열기**를 추가하고, 이미지 확장자를 **연결 프로그램** 목록과 기본 앱 후보에 등록하려면 설정 창에서 한 번 등록합니다.

1. 상단 바의 **설정**을 엽니다.
2. 맨 아래 **탐색기 연결**에서 **등록**을 누릅니다.
3. **설정** → **앱** → **기본 앱**에서 사진뷰어를 **달빛뷰어**로 변경합니다.

**등록해도 기본 앱은 바뀌지 않습니다.** 달빛뷰어를 기본 앱으로 쓰려면 등록 후 Windows에서 한 번 더 지정합니다.

연결되는 확장자: BMP, JPG, JPEG, JFIF, JPE, PNG, GIF, WebP, TIFF, TIF, AVIF, ICO, PPM, PGM, PNM, JXL, DDS, TGA, CBZ, ZIP

압축파일(CBZ/ZIP)은 기본 앱을 바꾸지 않고 우클릭 메뉴 항목만 추가되므로, 기존 압축 프로그램 연결은 그대로 유지됩니다.

Windows 정책상 프로그램이 기본 앱을 직접 바꿀 수는 없어서, 위 과정을 한 번은 직접 거쳐야 합니다. 한 번 지정하면 이후부터는 더블클릭으로 열립니다.

## 조작

| 조작 | 동작 |
|---|---|
| Esc, 상단 바 ✕ | 종료 |
| ← → ↑ ↓ / WASD | 확대 상태에서 화면 이동. 끝에 닿으면 이전/다음 |
| PageUp / PageDown, Space / Backspace | 이전 / 다음 |
| Home / End | 처음 / 마지막 |
| 마우스 휠 | 설정에 따라 이전/다음 또는 확대/축소 (기본: 이전/다음) |
| Ctrl + 마우스 휠 | 설정에 따라 확대/축소 또는 이전/다음 (기본: 확대/축소) |
| 9 / 8 / 0 | 화면 맞춤 / 너비 맞춤 / 원본 크기 |
| 더블클릭 | 화면 맞춤 ↔ 원본 크기 |
| 드래그 | 확대된 이미지 이동 |
| Alt+Enter | 전체화면 ↔ 창모드 |
| Ctrl+O | 파일 열기 |
| Ctrl+S | 설정 열기 |
| L | 열람한 목록 |
| 마우스를 화면 위로 | 상단 바 표시 |
| 마우스를 화면 아래로 | 하단 슬라이드바 표시 |

단축키는 설정 → 단축키 설정에서 바꿀 수 있습니다. 일부 키(방향키, PageUp/PageDown, Space 등)는 고정입니다.

## 설정

상단 바의 설정 버튼 또는 `Ctrl+S`로 엽니다. 바꾼 값은 즉시 적용되고 저장됩니다.

- **언어**: 한국어 / English. 첫 실행에서만 Windows 표시 언어를 따르고, 이후에는 이 설정에서 바꿉니다.
- **보간기법**: 확대/축소 품질. 선택한 기법의 설명이 창에 표시됩니다.
- **이미지 크기**: 새 이미지를 열 때의 기본 크기
- **마우스 휠 동작**: 휠/ Ctrl+휠 역할 선택
- **배경색**: 검정 / 어두운 회색 / 흰색
- **하단 슬라이드바**: 자동 표시 / 항상 표시 / 표시 안 함
- **처음/끝 동작**: 반복 / 멈춤 / 다음 항목으로 이동 (폴더·압축파일)
- **다음 항목 순서**: '다음 항목으로 이동'을 선택했을 때만 사용

## 지원 형식

- 이미지: JPG, PNG, GIF, WebP, TIFF, BMP, AVIF 등 Pillow가 지원하는 형식
- 압축파일: ZIP, CBZ (풀지 않고 바로 보기)
- 애니메이션 GIF/WebP 재생 지원
- HEIC/HEIF, RAW, RAR/CBR은 지원하지 않습니다

## 파일 위치

`settings.json`, `viewed_folders.json`은 실행 파일(또는 `main.py`) 옆에 저장됩니다. 이미지 로딩에 실패하면 같은 위치의 `viewer_error.log`에 원인이 기록됩니다.
