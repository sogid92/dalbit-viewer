# 달빛뷰어 (Dalbit Viewer)

전체화면으로 이미지를 보는 Windows용 뷰어입니다. UI는 필요할 때만 나타납니다.

**English:** [README.en.md](README.en.md)

## 실행법

**EXE로 실행**

[Releases](https://github.com/sogid92/dalbit-viewer/releases)에서 `DalbitViewer-<버전>-win64.zip`을 받아 압축을 풀고 `DalbitViewer\DalbitViewer.exe`를 실행합니다. 폴더 안의 파일을 지우거나 EXE만 따로 옮기면 실행되지 않으니 폴더째로 두세요.

**소스로 실행** (Python 3.10 이상)

```bat
pip install -r requirements.txt
python main.py [이미지 / 폴더 / ZIP / CBZ 경로]
```

경로를 생략하면 파일 선택 창이 열립니다. 이미지 파일 대신 폴더나 압축파일을 열 수도 있습니다.

## 연결 프로그램 설정

이미지를 더블클릭했을 때 달빛뷰어로 열리게 하려면 Windows에 한 번 등록합니다.

**방법 1: 파일 우클릭**

1. 이미지 파일을 우클릭합니다.
2. **연결 프로그램** → **다른 앱 선택**을 누릅니다.
3. 목록에 없으면 **PC에서 앱 찾기**로 `DalbitViewer\DalbitViewer.exe`를 선택합니다.
4. **항상 이 앱 사용**을 체크하고 확인합니다.

**방법 2: Windows 설정**

1. **설정** → **앱** → **기본 앱**을 엽니다.
2. 연결할 확장자(예: `.jpg`, `.png`)를 검색해 클릭합니다.
3. 목록에서 **달빛뷰어**를 선택합니다.

확장자마다 따로 지정해야 합니다. 연결되는 확장자: BMP, JPG, JPEG, JFIF, PNG, GIF, WebP, TIFF, AVIF, ICO, PPM, JXL, DDS, TGA, CBZ

Windows 정책상 프로그램이 기본 앱을 직접 바꿀 수는 없어서, 위 과정을 한 번은 직접 거쳐야 합니다. 한 번 지정하면 이후부터는 더블클릭으로 열립니다.

## 조작

| 조작 | 동작 |
|---|---|
| Esc, 상단 바 ✕ | 종료 |
| ← → ↑ ↓ / WASD | 확대 상태에서 화면 이동. 끝에 닿으면 이전/다음 |
| PageUp / PageDown, Space / Backspace | 이전 / 다음 |
| Home / End | 처음 / 마지막 |
| 마우스 휠 | 설정에 따라 이전/다음 또는 확대/축소 (기본: 이전/다음) |
| Ctrl + 마우스 휠 | 설정에 따라 확대/축소 또는 이전/다음 (기본: 확대/축소) |
| 9 / 8 / 0 | 화면 맞춤 / 너비 맞춤 / 원본 크기 |
| 더블클릭 | 화면 맞춤 ↔ 원본 크기 |
| 드래그 | 확대된 이미지 이동 |
| Alt+Enter | 전체화면 ↔ 창모드 |
| Ctrl+O | 파일 열기 |
| Ctrl+S | 설정 열기 |
| L | 열람한 폴더 목록 |
| 마우스를 화면 위로 | 상단 바 표시 |
| 마우스를 화면 아래로 | 하단 슬라이드바 표시 |

단축키는 설정 → 단축키 설정에서 바꿀 수 있습니다. 일부 키(방향키, PageUp/PageDown, Space 등)는 고정입니다.

## 설정

상단 바의 설정 버튼 또는 `Ctrl+S`로 엽니다. 바꾼 값은 즉시 적용되고 저장됩니다.

- **언어**: 한국어 / English. 첫 실행에서만 Windows 표시 언어를 따르고, 이후에는 이 설정에서 바꿉니다.
- **보간기법**: 확대/축소 품질. 선택한 기법의 설명이 창에 표시됩니다.
- **이미지 크기**: 새 이미지를 열 때의 기본 크기
- **마우스 휠 동작**: 휠/ Ctrl+휠 역할 선택
- **배경색**: 검정 / 어두운 회색 / 흰색
- **하단 슬라이드바**: 자동 표시 / 항상 표시 / 표시 안 함
- **처음/끝 동작**: 반복 / 멈춤 / 다음 폴더로 이동
- **다음 폴더 순서**: '다음 폴더로 이동'을 선택했을 때만 사용

## 열람한 폴더 목록 (L)

`다음 폴더로 이동`으로 폴더를 넘길 때 본 폴더가 자동으로 기록됩니다. 목록에서 체크한 폴더를 Windows 휴지통으로 보내거나, 목록에서만 제거할 수 있습니다. 드라이브 루트, 사용자 홈, Windows 기본 폴더, 시스템 폴더는 삭제할 수 없습니다.

## 지원 형식

- 이미지: JPG, PNG, GIF, WebP, TIFF, BMP, AVIF 등 Pillow가 지원하는 형식
- 압축파일: ZIP, CBZ (풀지 않고 바로 보기)
- 애니메이션 GIF/WebP는 첫 프레임만 표시
- HEIC/HEIF, RAW, RAR/CBR은 지원하지 않습니다

## 파일 위치

`settings.json`, `viewed_folders.json`은 실행 파일(또는 `main.py`) 옆에 저장됩니다. 이미지 로딩에 실패하면 같은 위치의 `viewer_error.log`에 원인이 기록됩니다.
