# 달빛뷰어 — 미니멀 전체화면 버전

이미지를 열면 **이미지 하나만 전체화면**으로 보여주는 데스크톱 프로그램입니다.
전체화면에서는 상단 바가 숨겨져 있고, 마우스를 화면 맨 위로 올리면 나타납니다.
- **상단 바**: 파일 탭(파일 열기 / 압축파일 열기 / 열람 목록) + 설정(Settings) 탭 + 창 버튼 + 전체화면 버튼
- **Alt+Enter**: 전체화면 ↔ 창모드
- **L 키**: 열람한 폴더 목록 (실제 삭제는 휴지통으로 이동)
- **마우스를 화면 아래로 내리기**: 현재 폴더 내 빠른 탐색 슬라이드바
- **마우스 커서**: 2초간 움직이지 않으면 자동으로 숨겨지고, 움직이면 다시 나타납니다. 페이지 이동·줌 등 동작을 취하면 바로 숨겨집니다.

프로그램명: **달빛뷰어 (DalbitViewer)** — 이전 이름(BandiViewStyleViewer)에서 바꾼 이름입니다. 구버전으로 등록된 파일 연결이 있으면 `install.bat` / `uninstall.bat` 실행 시 함께 정리됩니다. 아이콘은 `icon.ico`(달빛 초승달)이며, EXE 빌드 시 `--icon`으로 내장됩니다.

## 실행

```bat
pip install Pillow
python main.py [이미지 / 폴더 / 압축파일 경로]
```

- 경로를 안 주면 파일 선택 대화상자만 뜬 뒤, 선택한 이미지를 전체화면으로 엽니다.
- 이미지 하나를 열면 같은 폴더의 이미지들을 함께 불러와 방향키로 이동할 수 있습니다.
- 폴더를 열면 그 폴더의 이미지들을, ZIP/CBZ를 열면 압축을 풀지 않고 안의 이미지들을 봅니다.

## 탐색기에서 더블클릭으로 열기 (한 번만 설정, Windows)

`install.bat`을 더블클릭하세요. 한 번만 하면 됩니다. 순서대로 자동으로 처리합니다.

1. `dist\DalbitViewer\DalbitViewer.exe`를 **항상 새로 빌드**합니다 (구버전 EXE 재사용 안 함).
2. 현재 사용자로 파일 연결을 등록합니다 (관리자 권한 불필요, HKCU만 건드림).
3. 윈도우 기본 앱으로 지정 시도를 합니다.
4. 기본 앱 설정 화면을 열어 확인하게 합니다.

이후 탐색기에서 이미지를 더블클릭하면 이 프로그램으로 전체화면으로 열립니다.
연결되는 확장자: BMP, JPG, JPEG, JFIF, PNG, GIF, WebP, TIFF, AVIF, ICO, PPM, JXL, DDS, TGA, CBZ
(.zip은 압축 프로그램 연결을 빼앗지 않도록 일부러 제외했습니다.)

참고: Windows 10/11 보안 정책상 프로그램이 몰래 기본 앱을 바꿀 수 없습니다. 그래서 `install.bat`이 등록 + 기본 앱 지정 시도를 한 뒤, 혹시 안 된 경우를 대비해 기본 앱 설정 화면을 열어줍니다. 거기서 한 번만 "달빛뷰어"를 선택하면 이후부터 자동으로 열립니다. 처음 더블클릭 시 "어떤 앱으로 열까요?"가 뜨면 "달빛뷰어"를 선택하고 "항상"을 체크해도 됩니다.

해제하려면 `uninstall.bat`을 더블클릭하세요 (연결만 해제하고 EXE 파일은 남깁니다).
직접 명령으로 하려면 `dist\DalbitViewer\DalbitViewer.exe --register` / `--unregister`를 쓰면 됩니다.

### 파일 위치 (중요)

`install.bat` / `uninstall.bat` / `build_exe.bat` / `main.py`는 모두 압축을 푼 **`dalbit-viewer` 폴더 바로 안**에 있습니다.
`dist\DalbitViewer` 폴더 안에 `DalbitViewer.exe`와 실행에 필요한 파일들(`_internal` 등)이 함께 있고, `uninstall.bat`은 `dist` 안에 없습니다.
EXE 파일 하나만 따로 복사해 가면 실행이 안 되니, **배포할 때는 `dist\DalbitViewer` 폴더째로** 복사해서 보내세요. `uninstall.bat`이 없을 때는 전체 zip을 다시 풀어서 `dalbit-viewer\uninstall.bat`을 실행하세요.

### 더블클릭했는데 초기 화면만 뜨면 (문제 해결)

이건 대부분 **구버전 EXE**가 남아 있어서 생깁니다. 초기 버전 EXE는 탐색기가 넘겨준 이미지 경로를 무시하고 항상 빈 초기 화면만 띄웠습니다. 지금 `install.bat`은 항상 새로 빌드하도록 고쳤으니, `install.bat`을 다시 한 번 실행하면 해결됩니다.
확인 방법: 명령 프롬프트에서 `dist\DalbitViewer\DalbitViewer.exe --version`을 실행했을 때 `2026-11-09.10` 이상이 나와야 최신입니다. 그보다 낮거나 아무것도 안 나오면 구버전입니다.
그 외에 이미지가 열리지 않는 경우: 지원하지 않는 포맷(HEIC/HEIF, CLIP, 최신 RAW 등)이면 오류 창이 뜨고, 원인은 EXE 옆의 `viewer_error.log`에 남습니다. 연결할 파일은 반드시 `dist\DalbitViewer\DalbitViewer.exe`여야 하고, `main.py`나 `.bat` 파일을 연결하면 안 됩니다.

## 다른 사람에게 보내기 (Python 없는 PC)

1. `install.bat`을 실행해서 `dist\DalbitViewer` 폴더를 빌드하세요.
2. `register.bat`을 `dist\DalbitViewer` 폴더 안에 복사해 넣으세요 (EXE와 같은 폴더에 있어야 동작합니다).
3. `dist\DalbitViewer` 폴더째로 ZIP으로 압축해서 보내세요. EXE 하나만 보내면 실행이 안 됩니다.
4. 상대방은 ZIP을 풀고 `register.bat`을 더블클릭하면 탐색기 연결이 등록됩니다. 그 뒤부터 이미지 더블클릭하면 달빛뷰어로 열립니다.

## EXE로 만들기 (Windows에서만)

`build_exe.bat`을 더블클릭하면 `dist\DalbitViewer` 폴더(EXE + `_internal`)가 만들어집니다. `--onedir` 방식이라 시작할 때 압축을 푸는 과정이 없어 `--onefile`보다 시작이 빠릅니다.
(Python이 없는 PC에서도 실행 가능, 단 폴더째로 배포해야 함)
빌드 전에 기존 `settings.json`과 `viewed_folders.json`을 백업했다가 새 빌드에 복원하므로, 설정과 열람한 폴더 목록은 유지됩니다.
탐색기 연결까지 한 번에 하려면 `build_exe.bat` 대신 위의 `install.bat`을 쓰면 됩니다.

## 조작법

평상시에는 전체화면으로 이미지에 집중하고, 필요할 때만 상단 바를 불러냅니다. 아래 단축키는 기본값이며, 설정 → 단축키 설정...에서 바꿀 수 있습니다.

| 조작 | 동작 |
|---|---|
| Esc | 종료 |
| 상단 바 닫기(✕) | 종료 |
| ← → / ↑ ↓ / WASD | 확대 시 화면 스크롤(패닝). 끝에서 키를 뗐다가 다시 누르면 이전/다음 |
| PgUp PgDn / Space / BackSpace | 바로 이전 / 다음 (패닝 아님) |
| Home / End | 처음 / 마지막 |
| 마우스 휠 | 설정에 따라 이전/다음 또는 확대/축소 (기본: 이전/다음) |
| Ctrl + 마우스 휠 | 설정에 따라 확대/축소 또는 이전/다음 (기본: 확대/축소) |
| 9 | 화면에 맞추기 |
| 8 | 너비에 맞추기 |
| 0 | 원본 크기 (100%) |
| 더블클릭 | 화면 맞춤 ↔ 원본 토글 |
| 드래그 | 확대된 이미지 이동 |
| Alt+Enter | 전체화면 ↔ 창모드 토글 |
| Ctrl+O | 다른 파일 열기 (파일 선택 대화상자만 뜸) |
| Ctrl+S | 설정 열기 |
| L | 열람한 폴더 목록 열기 (휴지통 정리) |
| 마우스를 화면 위로 | 전체화면에서 상단 바(파일/설정/창 버튼) 표시 |
| 마우스를 화면 아래로 내리기 | 하단 슬라이드바 표시 (빠른 탐색) |

확대했을 때 스크롤: Ctrl+휠(설정에 따라 휠)로 확대하면 방향키(← → ↑ ↓)와 WASD(W=위, A=왼쪽, S=아래, D=오른쪽)로 화면을 자유롭게 이동할 수 있습니다. 예를 들어 오른쪽 끝까지 닿은 상태에서 키를 계속 누르고 있어도 페이지가 넘어가지 않고, 키를 뗐다가 →(D)를 다시 눌러야 다음 이미지로 이동합니다. 왼쪽 끝에서 ←(A), 아래 끝에서 ↓(S), 위 끝에서 ↑(W)도 마찬가지입니다. 맞춤 보기(스크롤 불가)에서는 방향키/WASD가 바로 이전/다음으로 동작합니다.

방향키/WASD를 꾹 누르면 화면이 멈추지 않고 가장 최근 이미지를 계속 갱신합니다. 누르고 있는 동안은 보간기법 없이(NEAREST) 빠르게 그리고, 키를 떼면 설정된 보간기법으로 최종 화질을 다시 그립니다. 이미지 로딩이 느리면 중간 이미지를 건너뛸 수 있지만, 현재 위치는 계속 보입니다. 이 동작은 PageUp/PageDown/Space/Backspace 페이지 이동 키에도 적용됩니다.

## 상단 바 (파일 / 설정)

전체화면에서는 상단 바가 숨겨져 있고, 마우스를 화면 맨 위로 올리면 나타납니다. 마우스를 아래로 내리면 다시 숨겨집니다. 창모드에서는 항상 표시됩니다.

- **파일 탭**: 파일 열기... (O) / 압축파일 열기... (ZIP/CBZ) / 열람한 폴더 목록... (L)
- **설정(Settings) 탭**: 설정 창을 바로 엽니다. (Ctrl+S와 동일)
- **오른쪽 버튼**: 전체화면 아이콘, 최소화, 최대화, 닫기. 전체화면 아이콘은 최소화 바로 왼쪽에 있습니다.
- 창모드에서도 상단 바가 제목 표시줄 역할을 하며, 창은 상단 바의 빈 곳을 드래그해 이동하고 오른쪽 아래 ◢ 그립으로 크기를 조절합니다.
- 전체화면에서는 상단 바가 숨겨져 있고, 마우스를 맨 위로 올리면 같은 버튼들이 나타납니다. 상단 바 버튼에 마우스를 올리면 이름이 표시됩니다.
- 전체화면에서 창모드로 나오면 창이 다른 창 뒤로 밀리지 않도록 앞에 표시됩니다. 다른 앱을 클릭하면 일반 창처럼 뒤로 갑니다.
- Alt+Enter로도 전체화면을 전환할 수 있습니다.

## 설정 (상단 설정(Settings) 탭 / Ctrl+S 키)

설정 창에서 바꾸면 `settings.json`에 저장되어 다음 실행에도 유지되고, 바로 적용됩니다.

- **언어**: 한국어 / English. 첫 실행 때만 PC의 Windows 표시 언어를 따라 자동으로 정해지고, 그 뒤에는 이 설정에서만 바꿀 수 있습니다. 언어를 바꾸면 화면과 설정 창이 즉시 새 언어로 바뀝니다.
- **보간기법**: 확대/축소 품질. 선택한 기법의 성능/화질 설명이 아래에 표시됩니다.
- **이미지 크기**: 새 이미지 열 때 기본 크기 (너비 맞춤 (8) / 화면 맞춤 (9) / 원본 100% (0))
- **마우스 휠 동작**: 휠=이동 + Ctrl+휠=확대/축소 (기본) / 휠=확대/축소 + Ctrl+휠=이동
- **배경색**: 검정 / 어두운 회색 / 흰색
- **하단 슬라이드바**: 마우스 아래로 내리면 표시 (기본) / 항상 표시 / 표시 안 함
- **처음/끝 동작**: 반복 (기본, 끝에서 다시 처음으로 / 처음에서 끝으로) / 멈춤 (끝에서 더 이상 이동 안 함) / 다음 폴더로 이동 (끝에서 다음 폴더의 첫 이미지로, 처음에서 이전 폴더의 마지막 이미지로)
- **다음 폴더 순서**: 이름 오름차순 (기본) / 이름 내림차순 / 수정날짜 오름차순 / 수정날짜 내림차순 — 처음 연 폴더의 부모 아래의 폴더들을 이 순서로 이웃으로 봅니다. 빈 폴더는 건너뜁니다. **‘다음 폴더로 이동’을 선택했을 때만 활성화됩니다.** **이동 범위는 처음 연 폴더의 부모 아래로 고정되며, 그 범위를 다 보면 멈추고 더 상위로 올라가지 않습니다.** 새 폴더의 이미지를 직접 열면(파일 열기/탐색기) 이동 범위가 새로 정해집니다.

## 단축키 설정

설정 창 → **단축키 설정...**에서 다음 단축키를 바꿀 수 있습니다. 키 버튼을 누른 뒤 새 키를 누르면 바로 저장됩니다. **기본값**으로 복원할 수 있습니다. Alt 조합은 저장되지 않습니다.

- 설정 가능: 너비 맞춤, 화면 맞춤, 원본 크기, 설정, 열람한 폴더 목록
- 기본 조작:
  - 방향키 / WASD: 확대 시 화면 이동, 맞춤 보기에서는 이전·다음
  - PageUp / PageDown, Space / Backspace: 이전·다음
  - Home / End: 처음·마지막
  - Alt+Enter: 전체화면
  - Ctrl+O: 파일 열기
  - 마우스 휠: 설정에 따라 이동/확대·축소 (기본: 이동)
  - Ctrl + 마우스 휠: 설정에 따라 확대·축소/이동 (기본: 확대·축소)
  - Esc: 종료
- 변경한 단축키는 `settings.json`에 저장되어 다음 실행에도 유지됩니다.

## 열람한 폴더 목록 (L)

이미지를 끝까지 본 뒤 다음 폴더로 넘어가면(또는 마지막 폴더에서 다음을 누르면) 그 폴더가 자동으로 기록됩니다. 이 기록은 설정의 **처음/끝 동작**이 `다음 폴더로 이동`일 때 동작합니다. 압축파일(CBZ/ZIP)을 보다가 다음 폴더로 넘어가면 그 압축파일이 있는 폴더가 기록됩니다.
`L` 키 또는 상단 파일 탭 → 열람한 폴더 목록으로 엽니다. 목록은 `settings.json` 옆의 `viewed_folders.json`에 저장되어 다음 실행에도 유지됩니다.

- 각 폴더 앞의 **체크박스**로 대상을 고르고, 맨 위 **전체 선택**으로 모두 고를 수 있습니다. 체크한 항목이 없으면 아래 두 버튼은 비활성화됩니다.
- **체크한 폴더를 휴지통으로 이동**: 실제 폴더와 하위 파일을 Windows 휴지통으로 보냅니다. 확인 창에 대상 경로가 표시됩니다.
- **체크한 항목을 목록에서만 제거**: 프로그램 목록에서만 지우고 디스크는 건드리지 않습니다.
- 현재 보고 있는 폴더를 삭제하면 화면이 비워집니다.
- 안전상 드라이브 루트, 사용자 홈, 바탕화면/문서/다운로드/사진 같은 Windows 기본 폴더, Windows/Program Files/AppData, 프로그램이 설치된 폴더는 삭제할 수 없습니다.
- 휴지통을 사용할 수 없는 드라이브(네트워크, 일부 이동식)에서는 Windows가 영구 삭제 여부를 다시 묻습니다.
- 이전의 `__폴더명` 이름 변경 기능은 제거되었습니다. 폴더 이름은 바뀌지 않습니다.

## 하단 슬라이드바 (빠른 탐색)

마우스를 화면 맨 아래로 내리면 하단 한가운데에 너비 1/3짜리 슬라이드바가 나타납니다. 마우스를 위로 치우면 바로 사라집니다 (지연 없음).

- 슬라이더 트랙 아무 곳이나 누르면 그 위치의 페이지로 바로 이동합니다 (놓을 때까지 기다리지 않음, 미리보기 팁 없음). 드래그해도 누른 위치로 바로 이동합니다.
- 키보드 방향키/휠로 이동하면 슬라이더 위치도 같이 따라갑니다.
- 설정에서 항상 표시 / 표시 안 함으로 바꿀 수 있습니다.

## 이미지 보간기법 (확대/축소 품질 설정)

이미지를 확대/축소할 때 빈 픽셀을 어떤 방식으로 계산할지 정하는 설정입니다.
설정 창에서 바꿀 수 있고, `settings.json`에 저장되어 다음 실행에도 유지됩니다.

| 보간기법 | 특징 |
|---|---|
| NEAREST (최근접 이웃) | 가장 빠름. 화질 거침. 도트/픽셀아트용 |
| BOX (박스) | 빠름. 축소에 강함. 영역 평균 |
| BILINEAR (양선형) | 빠름. 부드러운 편. 주변 4픽셀 평균 |
| HAMMING (해밍) | 보통. 선명. 축소 시 디테일 유지 |
| BICUBIC (양3차) | 느린 편. 고화질. 주변 16픽셀 참조 |
| LANCZOS | 가장 느림. 최고 화질. 기본값 |

기본값은 LANCZOS입니다. 작은 이미지를 크게 볼 때 계단 모양 그대로 보고 싶으면 NEAREST, 사진처럼 부드럽게 보고 싶으면 BICUBIC/LANCZOS를 쓰면 됩니다.
직접 설정 파일을 고치고 싶으면 `settings.json`의 `"interpolation"` 값을 위 이름 중 하나로 바꾸면 됩니다.

참고: 보간기법은 일반 이미지 뷰어/편집기에서 통용되는 표준 6종을 Pillow 필터로 구현했습니다.

## 지원

- 포맷: JPG / PNG / GIF / WebP / TIFF / BMP / AVIF 등 (Pillow 지원 범위)
- 압축파일: ZIP / CBZ (풀지 않고 바로 보기)
- 애니메이션 GIF/WebP: 첫 프레임만 표시

## 이 버전에서 뺀 기능 (사용자 요청)

정보/EXIF 패널, 실시간 필터(밝기·대비·채도·선명·감마·흑백/세피아/반전), 히스토그램, 썸네일 그리드/필름스트립, 2장 보기, 웹툰 보기, 슬라이드쇼, 이미지 변환 기능은 제거했습니다. 평상시 이미지에 집중하는 전체화면 보기 + 상단 파일/설정 바 + 하단 슬라이드바 + 보간기법만 남겼습니다.

## 솔직한 차이점

- **HEIC/HEIF, CLIP(클립스튜디오), RAW 최신 포맷, HDR 출력**: 특허/전용 코덱 문제로 이 빌드에서는 지원하지 않습니다.
- **RAR/CBR**: 라이선스 문제로 지원하지 않습니다. ZIP/CBZ를 사용하세요.
- **해상도 제한**: 없음.
